# Куди вставляти коди та домен

Усе потрібне — в **одному файлі: `lib/site-config.ts`**. Відкрий його й заміни порожні лапки `""` на свої значення. Нічого більше в коді чіпати не треба.

| Що | Де в файлі | Приклад | Де взяти |
|---|---|---|---|
| Домен сайту | `SITE_URL` | `https://casprint.com.ua` | твій домен, без `/` в кінці |
| Google Analytics 4 | `TRACKING.gaId` | `G-ABC123DEF4` | analytics.google.com → Адмін → Потоки даних → Measurement ID |
| Google Ads (тег) | `TRACKING.googleAdsId` | `AW-123456789` | ads.google.com → Інструменти → Конверсії → Тег |
| Google Ads, конверсія «Покупка» | `TRACKING.googleAdsPurchaseLabel` | `AbCdEfGhIj` | у коді конверсії `send_to: 'AW-123456789/ЦЕЙ_ТЕКСТ'` — частина після `/` |
| Google Ads, конверсія «Заявка» (необов'язково) | `TRACKING.googleAdsLeadLabel` | `KlMnOpQrSt` | так само, для другої конверсії |
| Meta Pixel | `TRACKING.metaPixelId` | `123456789012345` | business.facebook.com → Events Manager → Pixel ID |
| Підтвердження в Google Search Console | `TRACKING.googleSiteVerification` | `xYz123...` | Search Console → Додати ресурс → HTML-тег → значення з `content="..."` |
| Підтвердження домену в Meta | `TRACKING.facebookDomainVerification` | `abc123...` | Meta Business → Безпека бренду → Домени → мета-тег → значення з `content="..."` |

Дані власника для політики конфіденційності (`SELLER.name`, `SELLER.email`) — **у цьому ж файлі**, нижче.

## Якщо сайт на Vercel
Те саме можна задати без редагування файлу: Vercel → Project → Settings → Environment Variables. Назви змінних записані в `.env.example` (блок «SEO / аналітика»). Після зміни — зроби Redeploy.

## Що вже налаштовано автоматично
- **Банер cookie** з'являється, лише якщо вставлений хоч один код. Google працює в режимі Consent Mode (без cookie до згоди), Meta Pixel вантажиться тільки після натискання «Прийняти».
- **Події:** перегляд товару, додавання в кошик, початок оформлення, покупка (з сумою зі знижкою), заявка на власний принт. Для Google Ads покупка й заявка стають конверсіями, коли вписані мітки.
- **SEO:** title/description/canonical на всіх сторінках, Open Graph та Twitter-картки, `sitemap.xml`, `robots.txt`, структуровані дані (Organization, WebSite, Product, BreadcrumbList). Кошик, оформлення, пошук і адмінка закриті від індексації.

## Перевірка після запуску
1. Відкрий сайт з розширенням **Google Tag Assistant** та **Meta Pixel Helper**, натисни «Прийняти» у банері.
2. У GA4 → Звіти → У реальному часі має з'явитись твій візит.
3. Зроби тестове замовлення — у Meta Events Manager → Test events побачиш Purchase.
4. Надішли `https://ТВІЙ-ДОМЕН/sitemap.xml` у Google Search Console.
5. Перевір прев'ю посилання: https://developers.facebook.com/tools/debug/
